一款简约清新的 Windows 桌面文本编辑工具。
Mark = Markdown（马克），Hunter = 猎手：
执笔如猎手般精准，让每一段文字都无所遁形。

----------------------------------------------------------------
 一、功能一览
----------------------------------------------------------------

[文件管理]
  · 左侧栏选择本地目录，树形浏览（懒加载、目录/文件图标、大小显示）
  · 侧栏按钮：新建文件 / 新建目录 / 刷新；右键菜单：新建/重命名/删除
  · 删除有确认提示，防止误删
  · 收藏常用目录：工具栏「☆ 收藏」把当前目录加入左栏收藏列表，点击即可一键切换工作目录（最多 50 个）

[编辑]
  · 支持 .md / .txt / .json / .py，自动语法高亮
  · 多标签打开、切换、关闭；未保存有圆点标记
  · 自动保存（输入防抖写盘，间隔可在设置调整）
  · 自动换行开关（设置中调整）
  · 大文件保护：超过上限（默认 50MB）拒绝打开，上限可调 1~2048MB
  · 光标始终可见（失焦后半透明显示）

[Markdown 预览]
  · 编辑 / 分屏 / 仅预览 三模式（Ctrl+B 切换）
  · 分屏分隔条可拖拽调整左右宽度（双击恢复等分）
  · mermaid 图渲染（流程图/时序图/类图/甘特图等）
  · Ctrl + 滚轮缩放预览（50%~300%，Ctrl+0 重置）

[搜索]
  · 文件内搜索（Ctrl+F）：底部面板一次性列出全部匹配，点击跳转，编辑器同步高亮
  · 全局搜索（Ctrl+Shift+F）：左侧栏展示，按文件分组，点击打开定位

[图片]
  · 文件树点击 .png/.jpg/.gif/.webp/.bmp/.svg/.ico 在编辑区查看
  · 图片标签页：滚轮缩放、左键拖拽平移、一键复制
  · md 中粘贴图片自动保存到同目录并插入引用
  · 双击预览中的图片或 mermaid 图打开详情查看器：
    滚轮缩放、左键拖拽平移、一键复制、查看详情（名称/尺寸/大小/路径）

[Python 运行]
  · 运行当前 .py（工具栏「运行」按钮）
  · 解释器自动检测（python/py/python3 + 注册表 + 常见路径）或手动选择
  · 输出面板内嵌展示 stdout/stderr（分色）、退出码、耗时，可终止

[其它]
  · 设置面板：解释器路径 / 大文件上限 / 保存间隔 / 自动换行 / 滚动条宽度（6~40px）
  · 简约清新浅色主题

----------------------------------------------------------------
 二、快捷键
----------------------------------------------------------------

  Ctrl+O            选择目录
  Ctrl+S            保存当前文件
  Ctrl+Shift+F      全局搜索（左侧栏）
  Ctrl+F            文件内搜索（底部面板）
  Ctrl+Shift+F      全局搜索
  Ctrl+B            预览模式切换（编辑/分屏/仅预览）
  Ctrl+0            预览缩放重置
  Ctrl+W            关闭当前标签
  Esc               收起底部面板

  详情查看器内：滚轮缩放，左键拖拽平移
  图片标签页内：滚轮缩放，左键拖拽平移，双击恢复 100%

----------------------------------------------------------------
 三、开发运行
----------------------------------------------------------------

  npm install          # 安装依赖
  npm start            # 启动应用
  npm run smoke        # 运行端到端冒烟测试（55 项自动化验证）

----------------------------------------------------------------
 四、一键发布安装包
----------------------------------------------------------------

  npm run release              # 默认递增 patch 版本并打包（0.1.x -> 0.1.x+1）
  npm run release -- --minor   # 递增 minor 版本
  npm run release -- --major   # 递增 major 版本

脚本自动完成：递增版本号 → 安装依赖 → esbuild 构建前端 → electron-builder 打包 → 输出安装包路径。

安装包生成在 dist/MarkHunter-Setup-<版本>.exe，
拷贝到任何 Windows 机器双击安装即可（可自选安装目录、自动创建桌面快捷方式）。

> 未签名应用首次运行可能触发 Windows SmartScreen：点击「更多信息」→「仍要运行」即可。

----------------------------------------------------------------
 五、目录结构
----------------------------------------------------------------

  src/main/        主进程（窗口、IPC 文件 API、搜索、Python 进程、设置持久化、剪贴板）
  src/preload/     contextBridge 安全桥接
  src/renderer/    前端（编辑器/文件树/搜索/预览/查看器/设置，esbuild 打包）
  scripts/         build.js 构建、smoke.js 端到端测试、release.ps1 一键发布、gen_icon.py 图标生成
  dist/            发布产物（安装包）
